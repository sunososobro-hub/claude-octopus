# oct-sleep

End-of-day wrap-up: finalize work, update memories, prepare for rest.

Like sleeping at night — consolidate learnings before bed.

## Usage

```bash
/oct-sleep              # Complete end-of-day workflow
/oct-sleep --help       # Show help
/oct-sleep help         # Show help
```

## What It Does

Complete end-of-day routine:

```
😴 End-of-Day Wrap-up

1. Summary
   ✓ What did you accomplish?
   ✓ Key learnings?
   ✓ Blockers resolved?

2. Memory Update
   ✓ Update relevant memory files
   ✓ Archive completed tickets
   ✓ Save new patterns

3. Preparation
   ✓ Mark session complete
   ✓ Create final checkpoint
   ✓ Ready for /oct-wake next time

Session duration: 4h 32m
Work quality: ⭐⭐⭐⭐⭐
Next priorities: [listed from context]

✅ Sleep well — memories consolidated!
```

## Workflow

```
Day: /oct-wake → work (/oct-focus + /oct-rest) → /oct-dream → /oct-sleep
     🌅              👨‍💼                    💾          🌙          😴
```

## Difference from `/oct-rest`

| | `/oct-rest` | `/oct-sleep` |
|---|---|---|
| When | During work (every 30-60 min) | End of day |
| Purpose | Continue work | Finalize & archive |
| Saves | Progress checkpoint | Final summary |
| Next | Resume work | New day begins |

## What Happens

1. **You provide summary**
   - What was accomplished
   - Key decisions made
   - What's next
   
2. **System updates**
   - Memory files (bugs, features, patterns)
   - Mark completed items
   - Archive session
   
3. **Prepare for tomorrow**
   - Clean slate ready
   - Key context saved
   - Memories consolidated

## Tips

- Run at end of focused work block
- Great after completing a task or fixing a bug
- Pairs well with `/oct-dream` (optional before sleep)
- Tomorrow: `/oct-wake` + `/oct-recall` to resume
