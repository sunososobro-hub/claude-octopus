# oct-dream

Consolidate and organize your memories.

Like processing experiences during sleep.

## Usage

```bash
/oct-dream
```

## What It Does

Scans your memory system and suggests improvements:

```
🌙 Memory Consolidation

Scanning your memories...

Found:
✓ SYS-1859 completed (8月18日) → can archive
✓ SYS-1844 + SYS-1821 both FT-related → merge?
✓ feedback_auto_framework still relevant? verify...
✓ New pattern: use Haiku for search, Fable for RCA

Suggestions:
1. Merge FT-related bugs into "MLO FT Knowledge Base"
2. Archive completed tickets
3. Create "Auto-routing Best Practices" memory
4. Remove outdated technical specs

Apply? [Yes] [Preview] [Skip]
```

## Features

- Detects duplicate/overlapping memories
- Marks completed/archived items
- Merges related memories
- Extracts new patterns from your work
- Suggests optimizations

## Benefits

- Keeps memory system clean and efficient
- Reduces context bloat
- Finds connections you might miss
- Makes future searches faster
