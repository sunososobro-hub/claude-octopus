# oct-learn

Enable optional Claude Octopus features.

## Usage

```bash
/oct-learn              # Show available features to enable
/oct-learn oct-usage    # Enable specific feature
```

## What It Does

Shows features that are installed but currently disabled, and lets the user enable them.

## Available Optional Features

When run without arguments, show:

```
📚 Learn new behaviors

Per-response token usage → use /oct-watch enable
```

## Disabling

Use `/oct-forget` to remove tools.
